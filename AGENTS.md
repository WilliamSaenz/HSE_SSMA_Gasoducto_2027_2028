# Presentaciones mensuales de socios — HSE / SMP

Para preparar o editar una presentación de socios, consultar primero [la guía de trabajo](informes/GUIA_PRESENTACIONES_SOCIOS.md) y el registro del mes correspondiente.

La referencia visual aprobada por William es la presentación de octubre de 2026 v16. Reutilizar su estilo y dinámica; renovar cifras, fechas, estados y fotografías con evidencia del período solicitado. No arrastrar datos de octubre como vigentes para meses posteriores.

Usar como base el último archivo que aporte el usuario, preservando sus cambios. Entregar la presentación general integrada y editable, con versión única y enlace de descarga verificado. Las instrucciones actuales del usuario prevalecen sobre esta guía y las decisiones históricas.
