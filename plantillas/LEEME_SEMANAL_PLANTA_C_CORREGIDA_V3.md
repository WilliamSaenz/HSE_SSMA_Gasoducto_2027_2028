# Semanal Planta V3 — reparación de fórmulas compartidas

La V2 produjo en Microsoft Excel un aviso de recuperación que identificó fórmulas y fórmulas compartidas de xl/worksheets/sheet4.xml, correspondiente a 03_TARJETAS_OBSERVACION. Esta entrega sustituye la V2.

Se expandieron 114.415 fórmulas compartidas de 51 hojas a fórmulas individuales equivalentes. No quedan grupos compartidos. Se verificó la equivalencia de las 245.823 fórmulas y la conservación de sus resultados calculados. Se mantienen las reparaciones funcionales de la V2, los datos del usuario, 87 hojas, imágenes, formatos y protecciones. La hoja de tarjetas sigue sin protección.

Validación: paquete ZIP íntegro, XML legible, sin referencias #REF!, sin vínculos a libros externos; recálculo completo independiente en copia temporal sin errores de celda. El archivo entregado conserva las partes nativas originales; no es una exportación de LibreOffice. No se pudo probar su apertura en Microsoft Excel de escritorio desde este entorno. Se conservan los avisos correspondientes a datos pendientes.

La copia vigente del paquete SharePoint es V5. No se realizó una carga real en SharePoint por falta de inicio de sesión.
